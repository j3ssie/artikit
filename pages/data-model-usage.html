          Methodology. How this data is collected.

          Updates
          Aggregated every hour. Days and weeks use UTC boundaries, so the current day is partial until midnight UTC.
          Tokens
          Input, output, reasoning, and cached tokens for each request. Cached tokens are counted at full weight so share figures stay comparable across providers.
          Users and sessions
          Approximate counts of distinct users and sessions. Counts are deduplicated per model per day; a user who runs two models counts once for each.
          Cost
          Session cost is the average spend per session. Token prices are list prices from the model catalog on the update date.
          Retention
          The share of a model's users in one week who use it again the next week. Weeks run Monday to Sunday.
          Citation
          Cite Model Data with the update timestamp shown at the top of the page. This page uses synthetic sample values.
