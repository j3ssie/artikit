re-read per step · deny wins
▸Each worker is a durable queue row. Its own workdir, its own pinned slice of the toolset.
▸Every worker acknowledges. The planner collects a reply down the same spoke it dispatched on, not fire-and-forget.
▸Nothing they hand back is a result. Code the model cannot reach re-runs it first.
▸The gate is re-read, not snapshotted. run stop or an expiry reaches a job already running.

A run comes back as one folder you can read, diff and replay.

The run folder

One run, one folder. ls answers what it wrote, rm -rf removes it, a tarball of it is the whole run.

every pass unions onto one table

The coverage table

One table, every pass unioned onto it. Bounds are decided before a row lands, and an out-of-bounds host is recorded, not dropped.

export → replay → closed

The evidence chain

Replayed, not asserted. On import the hash chain is recomputed against the manifest, and what lands is closed: a reading surface, never a launching pad.

two files · one is hashed

The result document

Each result is a pair: a redacted copy the chain hashes, and a raw twin kept unhashed. Purging the twin can never break a chain.
