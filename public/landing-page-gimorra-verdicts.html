        Quickstart

        Try one run

        Send state and named questions with your API key in the x-api-key header. Each answer comes back typed, with a probability, and the response lists the proofs behind it.

        state
        Shared context for every question, such as a target and a session
        questions
        Up to 100 named questions that share one crawl
        type
        bool for yes or no, choice for a fixed set of options, score for an ordered rubric
        instructions
        The question itself, in plain language

        FAQs
        
    
          
      
        • One verdict is one typed answer to one named question. A run can carry up to 100 questions against the same state, and each answered question is billed at $1 per 1,000.
          • 
      
        • bool for yes or no, choice for a fixed set of options such as a severity, and score for an ordered rubric. Every type returns a probability alongside the value.
          • 
      
        • Each answer links to the exact request and response pairs that settled it. Proofs are replayable, so a reviewer can re-run them against the target and get the same result.
          • 
      
        • The answer comes back with a low probability and no proof attached. Anything under your threshold is routed to review instead of being filed automatically.
          • 
      
        • Yes. The same endpoint is exposed over MCP and the CLI, and the response is plain JSON, so an agent can ask follow-up questions against the same session.
