Download

Artikit now ships three article templates: a narrative post, this release post and a research note. Each is one HTML file with its styles and its script inline.

They are made for writing, so the chrome is small: a wordmark and a scheme switch above, one line below. Everything between is the document.

What the three files share

Each template is built the same way, so moving a document from one to another means copying a single element.

  • One file and no build step
  • Colours, faces, sizes and spacing as tokens in :root
  • A light and a dark scheme that follow the system setting
  • A text column that holds a line near 70 characters
  • A header and a footer of one line each

Blocks to write with

The blocks are plain HTML elements with a class or two. Nothing is generated, so what you read in the source is what the browser draws.

Code with its file name

A code block carries the name of the file it comes from and a copy button. Inline code such as --measure sits in the line of text.

Tables as wide as a figure

A table may break out of the column the way a figure does. On a phone it scrolls sideways and the first column stays in view.

Start a new document

  1. Copy the file and rename it, keeping the blog- prefix
  2. Replace what is inside <article class="post"> with your own text
  3. Change the tokens in :root if the colours or the faces should differ
  4. Add the page to index.html and llms.txt so the chooser lists it

What is left out

There is no Markdown step, no syntax highlighting and no comment form. The templates are documents, and anything that needs a server is yours to add.
