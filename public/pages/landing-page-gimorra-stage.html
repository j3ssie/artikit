Install

Version 0.4.12-sample for macOS and Linux

Script
$ curl -fsSL cdn.sample.test/gimorra-8c2c9d08ee1a9427f90a0f7653caa2ad28686d26da77/install.sh | bash
First run
$ gimorra doctor
$ gimorra scan -t https://app.sample.test
$ gimorra findings report
For agents
$ gimorra skills install

With the skill, an agent can start a run, read its evidence trail, prove a stored finding again and render the report.
