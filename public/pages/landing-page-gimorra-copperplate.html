The boundary list

Deny wins; ambiguity blocks. Compiled before a request moves, checked on every step that names a host, before autonomy gets a say.

The verifier

The agent proposes; the verifier decides. A candidate is re-run host-side by the least invasive check, and the bytes are kept. Only confirmed is stored.

The rollback ledger

Every change ledgered, every change undone at teardown, so a run cannot close dirty.

orchestration

One goal in, specialist workers out.

dispatch → ack
re-read per step · deny wins
▸Each worker is a durable queue row. Its own workdir, its own pinned slice of the toolset.
▸Every worker acknowledges. The planner collects a reply back down the spoke it dispatched on, not fire-and-forget.
▸Nothing they hand back is a result. Code the model cannot reach re-runs it first.
▸The gate is re-read, not snapshotted. run stop or an expiry reaches a job already running, and a refused step sends nothing.

The run folder

One run, one folder. ls answers what it wrote, rm -rf removes it, a tarball of it is the whole run.

every source unions onto one table

The coverage table

One table, every pass unioned onto it. Bounds are decided before a row lands, and an out-of-bounds host is recorded, not dropped.

export → replay → closed

The evidence chain

Replayed, not asserted. On import the hash chain is recomputed against the manifest, and what lands is closed: a reading surface, never a launching pad.

addressed by content_sha256

The result document

A result is its evidence. The redacted copy is what the chain hashes; the raw copy is 0600 and never hashed.
